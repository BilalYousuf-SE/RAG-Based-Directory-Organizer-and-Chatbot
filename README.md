# AI Document Organizer

An AI-powered document organization system that:

- Discovers files
- Extracts text from multiple formats
- Chunks documents
- Generates embeddings
- Finds document relationships
- Performs clustering
- Generates category names
- Organizes documents automatically
- Supports RAG retrieval

## Tech Stack

- Python
- SentenceTransformers
- FAISS
- HDBSCAN
- KeyBERT
- YAKE
- Groq
- Gemini
